کرنسی: PKR — پاکستانی روپے۔ تمام بل اور رپورٹس پاکستانی روپے میں دکھائی جائیں گی۔\n\nMY SUPER STORE POS — ابتدائی ورژن

یہ ایک PWA (ویب ایپ) ہے۔ Android موبائل اور کمپیوٹر کے براؤزر میں چل سکتی ہے۔
اہم: یہ ابتدائی ورژن ہے، مکمل تجارتی/کلاؤڈ سسٹم نہیں۔

موجودہ خصوصیات:
- پروڈکٹ، بارکوڈ، خرید قیمت، فروخت قیمت، مقدار، کم اسٹاک حد اور ایکسپائری تاریخ
- فروخت/بل، کارٹ، کسٹمر، ادھار بیلنس اور وصولی
- سپلائر فہرست
- روزانہ/مجموعی سیل اور منافع کا بنیادی حساب
- اردو، پشتو، پرتگالی، انگلش (ترجمہ ابھی بنیادی ہے)
- رسید پرنٹ یا PDF محفوظ، WhatsApp پر خلاصہ شیئر
- مقامی ڈیٹا، آف لائن کھلنا، JSON بیک اپ/امپورٹ

اہم حدود:
1) ڈیٹا اسی ڈیوائس/اسی براؤزر میں محفوظ ہوتا ہے۔ موبائل اور کمپیوٹر کے درمیان خودکار Sync ابھی نہیں۔
2) حقیقی Cloud Sync کے لیے Firebase/Supabase جیسا backend، اکاؤنٹ لاگ اِن اور سیکیورٹی رولز لگانے ہوں گے۔
3) تھرمل پرنٹر کی مطابقت براؤزر، Android، پرنٹر اور کنکشن (Bluetooth/USB/Wi-Fi) پر منحصر ہے۔ پہلے ٹیسٹ پرنٹ کریں۔
4) کیمرہ بارکوڈ اسکین کے لیے HTTPS، کیمرہ اجازت اور BarcodeDetector سپورٹ ضروری ہے۔ متبادل USB/Bluetooth scanner کو کی بورڈ کی طرح استعمال کریں۔
5) ادھار/سپلائر ledger، خریداری انٹری، اسٹاک ایڈجسٹمنٹ، ٹیکس، returns، متعدد صارفین اور محفوظ لاگ اِن اگلے ورژن میں مکمل کرنے چاہئیں۔
6) کاروباری استعمال سے پہلے ڈیٹا کا بیک اپ لیں اور تمام حسابات ٹیسٹ کریں۔

GitHub Pages پر شائع کرنے کا آسان طریقہ:
1. GitHub میں نیا repository بنائیں: my-super-store-pos
2. اس ZIP کو Extract کریں اور اس کے اندر کی تمام فائلیں repository کے root میں Upload files سے اپ لوڈ کریں۔
3. Settings > Pages > Deploy from a branch > main > /(root) > Save منتخب کریں۔
4. بننے والا HTTPS لنک Android Chrome اور کمپیوٹر میں کھولیں۔
5. Android Chrome کے مینو سے Install app یا Add to Home screen کریں۔
6. پہلے ڈیوائس پر ٹیسٹ ڈیٹا درج کریں؛ دوسرے ڈیوائس پر وہ خود بخود نہیں آئے گا۔ فی الحال JSON Export/Import استعمال کریں۔

پہلا ٹیسٹ:
- ایک پروڈکٹ شامل کریں، مثال: Sugar 1kg، cost 100، sale 120، qty 10، low stock 2
- اسے Billing میں شامل کرکے ایک sale کریں
- ڈیش بورڈ میں سیل/منافع اور پروڈکٹ میں کم ہوتی مقدار دیکھیں
- Reports سے JSON backup Export کریں۔


اہم حدود:
- یہ ورژن PKR کرنسی استعمال کرتا ہے۔
- موبائل اور کمپیوٹر کے درمیان خودکار Cloud Sync ابھی شامل نہیں؛ بیک اپ Export/Import دستی ہے۔
- مکمل خریداری/سپلائر ادائیگی لیجر، کسٹمر ادائیگی کی مکمل تاریخ، صارف لاگ اِن، ٹیکس اور واپسی اگلے مرحلے میں درکار ہیں۔
- تھرمل پرنٹر اور کیمرہ اسکین حقیقی ڈیوائس پر ٹیسٹ کرنا ضروری ہے۔
- یہ ZIP بذاتِ خود APK نہیں ہے؛ Android میں اسے HTTPS ویب ایپ کے طور پر انسٹال کیا جا سکتا ہے۔
