MY SUPER STORE POS — Version 3.0
پاکستانی روپے (PKR) میں آف لائن POS سسٹم

اہم فیچرز:
- پروڈکٹ، بارکوڈ، اسٹاک، کم اسٹاک اور ایکسپائری الرٹس
- پروڈکٹ میں ترمیم اور حذف
- فروخت، کارٹ، رسید، پرنٹ/PDF اور WhatsApp شیئر
- گاہک اور ادھار بیلنس؛ ادائیگی کی ہسٹری
- سپلائر، خریداری، واجب الادا رقم اور ادائیگی کی ہسٹری
- سیلز ریٹرن اور واپس شدہ مال اسٹاک میں شامل کرنا
- روزانہ اخراجات اور اسٹاک ایڈجسٹمنٹ
- رپورٹ، JSON بیک اپ Export اور Import
- اردو، پشتو، پرتگالی اور انگریزی کے بنیادی نیویگیشن لیبل
- PWA اور آف لائن کیش

چلانے کا طریقہ:
1) تمام فائلیں ایک ہی فولڈر میں رکھیں۔
2) ویب ہوسٹنگ یا GitHub Pages پر اپلوڈ کریں۔ PWA/کیمرہ اسکین کے لیے HTTPS ضروری ہے۔
3) موبائل Chrome میں ویب سائٹ کھولیں اور Install app / Add to Home screen منتخب کریں۔
4) پہلے Test data کے ساتھ فروخت، خریداری، ریٹرن اور بیک اپ آزما لیں۔

اہم احتیاط:
- ڈیٹا اسی براؤزر/ڈیوائس کے Local Storage میں محفوظ ہے؛ خودکار Cloud Sync یا Login موجود نہیں۔
- موبائل/براؤزر کا ڈیٹا صاف کرنے یا ڈیوائس بدلنے سے پہلے Reports میں Export backup ضرور کریں۔
- ریٹرن مال کو اسٹاک میں واپس کرتا ہے؛ صارف کو رقم کی واپسی کی ادائیگی الگ نقدی حساب میں درج کریں۔
- Walk-in فروخت پر ادھار ہو تو اسے کسی گاہک کے کھاتے سے منسلک نہیں کیا جا سکتا؛ ادھار کے لیے گاہک منتخب کریں۔
- کاروباری استعمال سے پہلے اپنی اصل قیمتوں اور ڈیٹا کے ساتھ مکمل ٹیسٹ کریں۔
